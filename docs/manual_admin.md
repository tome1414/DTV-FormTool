## 1. 管理者ダッシュボードの概要

ログイン後、`/admin` ページが表示されます。

### 画面構成

```
┌─────────────────────────────────┬──────────────┐
│  申請一覧（検索・フィルター）        │  詳細パネル   │
│  ─────────────────────────      │  （右側に     │
│  申請番号 名前 ステータス 書類 日付  │   表示）      │
│  ─────────────────────────      │              │
│  ...                             │              │
└─────────────────────────────────┴──────────────┘
```

### タブ（オーナーのみ追加タブあり）

| タブ | 説明 | 利用可能ロール |
|---|---|---|
| 申請管理 | 申請一覧・書類確認・ステータス管理 | 全管理者 |
| ダッシュボード | 統計・グラフ・承認率 | オーナーのみ |
| 権限設定 | 管理者アカウント一覧・ロール確認 | オーナーのみ |

### サマリーカード（上部）

- **申請者総数** — 登録されている全申請者数
- **提出準備完了** — 大使館提出待ちの件数
- **書類不足** — 差し戻し中の件数

## 2. 申請一覧の操作

### 検索・フィルター

- **検索バー**: 氏名・申請番号・メールアドレスで絞り込み
- **ステータスフィルター**: プルダウンで特定ステータスのみ表示

### 書類ドット（カラーバッジ）

各申請行に7つの丸バッジが表示されます（1〜7番）：

| 色 | 意味 |
|---|---|
| ⚫ グレー | 未アップロード |
| 🟡 黄色 | アップロード済み・未確認 |
| 🟢 緑 | 管理者が承認済み |

**バッジの対応（番号順）:**
1. パスポート  2. 残高証明書  3. 顔写真  4. 滞在証明  5. 受入れレター  6. インボイス  7. 既存PDF

### 詳細パネルを開く

申請者の行をクリック → 右側に詳細パネルが開きます。  
もう一度クリックで閉じます。

## 4. 書類の確認と承認

### 書類一覧の各行

```
[番号バッジ] [書類名]  [未確認ラベル]  [👁] [✓] [△] [×]
```

| アイコン | 操作 | 説明 |
|---|---|---|
| 👁 | プレビュー | ファイルを全画面モーダルで確認 |
| ✓ | 承認 | 書類をOKとしてマーク（緑になる） |
| △ | 警告メモ | 修正が必要な点をメモとして追加 |
| × | 警告削除 | 警告メモを削除 |

### 承認の操作

1. 👁 でファイルを確認
2. 問題なければ ✓ をクリック → バッジが緑に変わる
3. 問題があれば △ で警告メモを入力 → 「保存」

> ⚠️ **自動検出警告（🤖マーク）**  
> パスポートの余白が多い、顔写真の背景が白でないなどをシステムが自動検出した場合、  
> 青い🤖バッジで警告が表示されます。目視でも確認してください。

### プレビューモーダルの操作

- 画像・PDFをモーダル内でプレビュー
- パスポートの場合は「パスポートをトリミング」ボタンが表示（→ セクション7参照）

## 5. ステータス変更とメール通知

### ステータス変更の手順

1. 詳細パネル上部のプルダウンからステータスを選択
2. 「保存する」ボタンをクリック
3. 確認モーダルが開く

### 確認モーダルの操作

**コメント入力欄（任意）**
- 申請者へのメッセージを英語で入力
- 書類不足・大使館修正依頼の場合は入力を推奨

**「申請者のマイページにも表示する」トグル**
- ONにすると申請者のマイページに通知ボックスとして表示される
- ONの場合、コメントに通知日時が自動付加される

**保存ボタン**

| ボタン | 動作 |
|---|---|
| 📧 保存してメール通知 | ステータス保存 + 申請者にメール送信 |
| 保存のみ | ステータス保存のみ（メールなし） |
| キャンセル | 変更を破棄 |

### ステータス一覧

| ステータス | 使うタイミング |
|---|---|
| レビュー中 | 書類確認中（デフォルト） |
| 書類不足 | 差し戻し・再提出依頼 |
| 提出準備完了 | 全書類確認完了・大使館提出前 |
| 大使館提出済み | 大使館へ提出した |
| 大使館修正依頼 | 大使館から追加書類要求があった |
| DTV承認 | ビザ承認完了 |

### メールプレビュー

確認モーダル内でメール本文のプレビューを確認できます。  
コメントを入力するとメール本文末尾に追記されます。

> ⚠️ コメントは**英語**で入力してください。  
> 外国籍の申請者には英語でメールが届きます。

### 書類不備通知（個別ボタン）

詳細パネル下部の「書類不備通知を送る」ボタンで、個別に通知メールを送ることができます。  
ステータス変更とは独立して動作します。

## 6. 管理者による書類アップロード

申請者が提出しない書類（受入れレター・インボイス・既存PDF一式）は管理者がアップロードします。

### アップロード対象書類

| 書類 | 説明 |
|---|---|
| 受入れレター（Acceptance Letter） | 学校・会社等からの受入れ証明 |
| インボイス（Invoice） | 申請費用の請求書 |
| 既存PDF一式（Existing PDF Bundle） | 過去提出書類等のまとめ |

### アップロード手順

1. 詳細パネルの「管理者書類アップロード」エリアを確認
2. 各書類の「クリックまたはドロップ」エリアにファイルをドロップ、またはクリックで選択
3. アップロード完了 → 「アップロード済み」バッジに変わる
4. 差し替えは 🔄 ボタン、削除は 🗑 ボタン

**対応形式:** PNG・JPG・PDF

## 7. パスポートのトリミング

余白が多いパスポート画像を管理者側でトリミングできます。

### 手順

1. 書類一覧のパスポート行 → 👁 でプレビューを開く
2. モーダル下部の「**パスポートをトリミング**」ボタンをクリック
3. モーダルが全画面に拡大し、パスポート画像が表示される
4. マウスでドラッグして**残したい範囲**を選択（青い枠が表示される）
5. 「**適用**」ボタンをクリック → トリミングされた画像で上書き保存される
6. 「キャンセル」で全画面を閉じてプレビューに戻る

> **操作のコツ**
> - カーソルが十字（＋）になっている状態でドラッグ
> - 範囲を選び直したい場合はそのままドラッグし直す
> - 適用後は元に戻せません。必要に応じて事前に原本を手元に保存してください

## 8. PDF一括ダウンロード

受入れレター・インボイス・既存PDF一式の3ファイルを**1つのPDFに結合**してダウンロードできます。

### ダウンロード可能条件

- 受入れレター・インボイス・既存PDF一式 — 3つすべてアップロード済みであること

### 手順

1. 詳細パネル下部の「PDF一括ダウンロード」ボタン（緑）をクリック
2. 生成中はスピナー表示
3. 完了後、自動でPDFファイルがダウンロードされる
4. ダウンロード後はボタンにファイルサイズが表示される（例：`PDF一括ダウンロード (567KB)`）

### 全書類ZIPダウンロード

申請者書類（パスポート・残高証明書・顔写真・滞在証明）と管理者書類がすべて揃っている場合、  
「ダウンロード」ボタン（青）でZIP形式の一括ダウンロードが可能です。

## 9. ダッシュボード・統計（オーナーのみ）

「ダッシュボード」タブで統計情報を確認できます。

### 表示内容

| セクション | 内容 |
|---|---|
| 申請〜承認ファネル | 総申請数 → 大使館提出 → 修正依頼/DTV承認 のフロー |
| DTV承認率 | 総申請数に対する承認数の割合（%） |
| ステータス別ドーナツチャート | 各ステータスの件数・割合 |
| 月別申請数グラフ | 直近6ヶ月の申請推移 |
| 国籍別件数 | 申請者の国籍分布 |
| 書類提出率 | 必須4書類のアップロード完了率 |

### 月次レポート通知

ナビバー右上の🔔（ベル）アイコンから月次レポートを確認できます。

## 10. 個人情報・データ管理ポリシー

### 保持期間ポリシー

| ケース | 保持期間 | 根拠 |
|---|---|---|
| **DTV承認済み** | 承認日から **5年間** | DTV有効期限に準ずる |
| **申請却下・未完了** | 最終更新日から **1年間** | 問い合わせ対応のため |
| **削除リクエスト受領後** | **30日以内**に対応 | 申請者からの要望 |

### 管理者が行うべき定期作業

現時点では自動削除機能は未実装です。定期的に以下を手動で確認してください。

**月次チェック推奨：**
1. Supabaseダッシュボードで申請一覧を確認
2. 最終更新から1年以上経過した「書類不足」「未完了」の申請をピックアップ
3. 該当申請者に連絡し、不要であればデータを削除

> ⚠️ 自動削除バッチは今後の実装予定です。実装まではオーナーが定期的に確認してください。

### アカウント削除リクエストへの対応手順

申請者から「データ削除希望」の連絡を受けた場合：

1. 受領日を記録する（30日以内に対応が必要）
2. Supabaseダッシュボード → Authentication → ユーザーを検索
3. 該当ユーザーのStorageファイル（`documents/` バケット内）を削除
4. `applications` テーブルの該当レコードを削除
5. Auth ユーザーアカウントを削除
6. 申請者に完了メールを送信

### 保存している個人情報の種類

| データ | 保存場所 |
|---|---|
| 氏名・メール・国籍・領事館 | `applications` / `profiles` テーブル |
| パスポート・残高証明書・顔写真・滞在証明等 | Supabase Storage `documents` バケット |
| ステータス変更履歴 | `status_history` テーブル |
| 管理者コメント | `applications.notes` カラム |

## 11. トラブルシューティング

### アプリが動かない / ログインできない

**原因**: Supabase（データベース）が一時停止している可能性があります。

**確認方法**: [supabase.com](https://supabase.com) にログインし、`dtv-formtool` プロジェクトの状態を確認。

**復帰手順**:
1. Supabaseダッシュボードで `dtv-formtool` プロジェクトを開く
2. 「プロジェクトは一時停止されています」と表示されていたら「**履歴書プロジェクト**」をクリック
3. 1〜2分待ってから再度アクセス

> Supabase無料プランは**7日間アクティビティがない**と自動停止します。  
> 週1回以上アクセスがある運用状況では停止しません。

### ファイルがプレビューできない

- ファイルが破損している可能性があります。申請者に再アップロードを依頼してください。
- PDFが暗号化・パスワード保護されている場合は開けません。

### メールが届かない

- 迷惑メールフォルダを確認するよう申請者に案内してください。
- 通知履歴は現在システム上では確認できません。

### トリミングが適用されない

- 「適用」ボタンを押す前に選択範囲（青い枠）が表示されているか確認してください。
- 範囲が小さすぎると保存されない場合があります。
