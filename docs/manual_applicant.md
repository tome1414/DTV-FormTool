## 1. はじめに

DTVポータルは、DTV申請に必要な書類をオンラインで提出・管理するための専用システムです。

**ポータルでできること**
- 必要書類のアップロード（スマートフォン・PCどちらからでも可）
- 申請ステータスのリアルタイム確認
- 担当者からのフィードバック受け取り

**申請の全体の流れ**

```
アカウント作成 → 書類アップロード → 担当者確認 → 大使館提出 → DTV承認
```

## 2. アカウント作成

### 2-1. アカウント登録画面を開く

`https://apply.dtvclub.com` にアクセスし、「アカウントを作成」をクリックします。

### 2-2. 必要事項を入力する

| 項目 | 説明 |
|---|---|
| 姓（Last Name） | パスポートと同じ綴りで入力 |
| 名（First Name） | パスポートと同じ綴りで入力 |
| ミドルネーム | ある場合のみ（任意） |
| メールアドレス | 通知メールが届くアドレス |
| パスワード | 6文字以上 |
| 国籍 | プルダウンから選択 |
| 申請予定の領事館 | 地域 → 国 → 公館の順に選択 |

> ⚠️ **領事館の選択について**  
> 「どこの領事館に申請するか」は担当者と事前にご確認ください。  
> 後からマイページで変更することも可能です。

### 2-3. 登録後のガイド画面

登録が完了すると「準備するものチェックリスト」が表示されます。  
アップロード前に必要書類を手元に揃えてください。

**アップロードに必要な4種類の書類**

| # | 書類名 | 形式 | 注意点 |
|---|---|---|---|
| 1 | パスポート写真ページ | JPG / PNG / PDF | 余白をトリミングする。顔・情報が鮮明に読めること |
| 2 | 残高証明書 | JPG / PNG / PDF | 残高50万バーツ（約200万円）以上が必要 |
| 3 | 顔写真 | JPG / PNG | 縦4.5cm×横3.5cm、白背景、正面向き。帽子・サングラス不可 |
| 4 | 滞在証明書類 | JPG / PNG / PDF | 申請国での滞在を証明する書類（詳細は下記） |

> **滞在証明書類について**  
> - 自国から申請：運転免許証または公共料金の請求書  
> - 第三国から申請：有効なビザ、ホテル領収書、タイ行き航空券など  
> ※ 領事館によって受付条件が異なります。担当者にご確認ください。

3. 「ログイン」をクリック → マイページまたは書類アップロード画面に移動

## 4. 書類のアップロード

### 4-1. アップロード画面の見方

ログイン後、「書類アップロード」ページが表示されます。

- **進捗バー**: 4種類中何件完了しているかを表示
- **各書類カード**: クリックで開閉。アップロード・プレビューが可能

### 4-2. ファイルをアップロードする

1. 書類名をクリックしてカードを開く
2. 点線のエリアをクリック、またはファイルをドラッグ＆ドロップ
3. ファイル選択後、自動でアップロードが開始される（スピナー表示）
4. アップロード完了 → 緑の ✓ マークが表示される

**対応形式:** PNG・JPG・PDF  
**スマートフォンから:** カメラで撮影したまま直接アップロード可能

### 4-3. アップロード済みファイルを確認・差し替えする

- 「プレビュー」タブで内容を確認できます
- 「差し替え」ボタンで上書きアップロードが可能です

### 4-4. 書類を送信する

4種類すべてアップロード完了後、「書類を送信する」ボタンが青く活性化します。  
ボタンをクリックして送信してください。

> ✅ 送信後は担当者が内容を確認します。通常1〜3営業日でステータスが更新されます。

## 5. マイページで状況確認

ログイン後「マイページ」から申請状況をいつでも確認できます。

### 5-1. ステータスの種類

| ステータス | 意味 |
|---|---|
| 🔵 レビュー中 | 担当者が書類を確認中 |
| 🔴 書類不足 | 差し替えや追加書類が必要 |
| 🟢 提出準備完了 | 書類確認完了。大使館提出待ち |
| 🟣 大使館提出済み | 大使館に提出しました |
| 🟠 大使館修正依頼 | 大使館から追加書類の要求あり |
| 💚 DTV承認 | ビザ承認！おめでとうございます |

### 5-2. 4ステップ進捗バー

```
[1 書類提出] → [2 書類確認] → [3 提出準備完了] → [4 大使館提出]
```

現在のステップが青く表示されます。

### 5-3. 書類一覧

- ✅ 提出済み（緑）
- ➖ 未提出（グレー）
- 各行の👁アイコンでファイルをプレビュー
- 🔄 アイコンで差し替えアップロード

## 6. 管理者からのコメントが届いたら

担当者がマイページにコメントを残した場合、ページ上部に**黄色または赤の通知ボックス**が表示されます。

```
⚠️ 書類に不備があります
通知日：2026-05-19
〔コメント内容〕
                              [確認した]
```

### 対応手順

1. コメントの内容を確認する
2. 指摘された書類を修正して再アップロードする
3. 対応完了後「**確認した**」ボタンをクリック → コメントが非表示になる

> ⚠️ 「確認した」を押してもステータスは自動で変わりません。  
> 書類の差し替えが完了したら担当者にご連絡ください。

## 7. 個人情報の取り扱い

### 保存される情報

DTVポータルでは、申請処理に必要な以下の個人情報を収集・保存します。

| 情報 | 用途 |
|---|---|
| 氏名・メールアドレス | 申請者の識別・通知送信 |
| 国籍・申請先領事館 | 申請先の管理 |
| パスポート・残高証明書・顔写真・滞在証明書類 | DTV申請書類として使用 |
| 申請ステータス履歴 | 申請進捗の記録 |

### データ保持期間

| ケース | 保持期間 |
|---|---|
| **DTV承認済み** | 承認日から **5年間**（DTV有効期限に準ずる） |
| **申請却下・未完了** | 最終更新日から **1年間** |

> DTV（Destination Thailand Visa）は最長5年の有効期限を持つビザです。  
> 有効期間中のお問い合わせに対応するため、承認後5年間データを保持します。

### アカウント削除について

ご自身のデータ削除をご希望の場合は、担当者までご連絡ください。  
ご連絡から **30日以内** にアカウントおよび関連データを削除いたします。

> ⚠️ 削除後はデータの復元ができません。申請関連書類は事前にご自身でバックアップしてください。

## 8. よくある質問

**Q. パスワードを忘れました**  
A. 現在パスワードリセット機能は準備中です。担当者にご連絡ください。

**Q. 書類はいつまでに提出すればいいですか？**  
A. 担当者からご案内した期限をご確認ください。

**Q. アップロードできるファイルサイズの上限はありますか？**  
A. 1ファイルあたり50MBまでです。PDFはできるだけ圧縮してください。

**Q. スマートフォンから操作できますか？**  
A. はい。`apply.dtvclub.com` はスマートフォンに対応しています。

**Q. 残高証明書の金額が50万バーツに満たない場合は？**  
A. 担当者にご相談ください。対応方法をご案内します。

**Q. 申請国の領事館を変更したい**  
A. 書類アップロード画面の「申請者情報」の「変更」ボタンから修正できます。
